Wtyczka odpowiedzialna za pobieranie danych za pośrednictwem usługi ULDK GUGiK.

Narzędzie pozwala na pobieranie obrysów:
- Działek
- Obrębów
- Gmin
- Powiatów
- Województw
  
Dostępne są trzy metody wyboru obiektów:
- Kliknięcie na mapie
- Wybór wg numeru TERYT
- Kaskadowy wybór z listy (Województwo -> Powiat -> Gmina -> Obręb)

Do prawidłowego działania listy kaskadowej niezbędne jest umieszczenie w tym samym folderze pliku .json ze słownikiem. W razie potrzeby jego aktualizacji, można to zrobic za pomocą dołaczonego skryptu.
